# Python Backend Project

Este proyecto fue desarrollado como parte de mi formación en desarrollo backend con Python.

## Objetivos

- Aplicar principios de programación limpia.
- Practicar testing automatizado con Pytest.
- Mejorar la organización y estructura de proyectos Python.
- Utilizar entornos virtuales y buenas prácticas de desarrollo.

## Tecnologías

- Python
- Pytest
- Git
- GitHub

## Características

- Código modular y mantenible.
- Pruebas unitarias automatizadas.
- Validación de funcionalidades mediante testing.
- Estructura preparada para futuras ampliaciones.

## Aprendizajes

Durante este proyecto reforcé conceptos como:

- Creación de pruebas unitarias.
- Parametrización de casos de prueba con `@pytest.mark.parametrize`.
- Organización de proyectos Python.
- Flujo de trabajo con Git y GitHub.
